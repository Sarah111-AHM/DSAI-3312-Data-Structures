## Course Description
This course introduces the fundamental building blocks of computer science and software development using Python.  
Students learn how to organize, manage, and process data efficiently through core data structures and algorithms, enabling scalable, efficient, and reliable software development.

---

## Learning Objectives
- Understand abstract data types and core data structures  
- Analyze time and space complexity  
- Implement data structures using Python  
- Apply algorithmic thinking to solve problems  
- Use data structures in real-world scenarios

##  Repository Structure (Weekly)

Each folder corresponds to one week of the syllabus and contains lecture notes, lab code, and practice examples.

Topics include:
- Data Structures fundamentals
- Complexity analysis
- Arrays, linked lists, stacks, queues
- Recursion and searching
- Sorting algorithms
- Trees, graphs, and hash tables
